# API
`GET /health` is public. Authenticated endpoints use `Authorization: Bearer <Supabase access token>`. Core endpoints: `/api/channels`, `/api/projects/:channelId`, `/api/jobs`, `/api/jobs/:id`, `/api/commands`, `/api/pipeline/:step`, `/api/workers`, `/api/faults?channel_id=...`, `/api/analytics?channel_id=...`, `/api/settings`, `/api/youtube/connect`, `/api/youtube/sync`.
